# IndiaMART LED Products – Data Collection & EDA

## 📌 Project Overview
This project is an end-to-end data engineering and exploratory data analysis (EDA)
exercise focused on collecting and analyzing product data from a B2B marketplace.

The data was scraped from **IndiaMART**, targeting the **LED Lighting Products**
category. The objective is to demonstrate the ability to:
- Collect structured data responsibly
- Clean and transform raw data
- Perform exploratory data analysis
- Derive meaningful business insights

---

## 🛠 Tools Used
- **Python 3**
- **Libraries**
  - pandas
  - requests
  - beautifulsoup4
  - fake-useragent
  - re
  - matplotlib
  - seaborn
- **Jupyter Notebook** for EDA
- **JSON / CSV** for data storage
